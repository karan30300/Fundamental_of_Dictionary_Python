# Fundamental_of_Dictionary_Python

🧠 Topics Demonstrated

The script covers the following dictionary concepts:
  Creating a dictionary using key–value pairs
  Storing multiple data types as dictionary values
  Accessing dictionary values using keys
  Handling errors when accessing non-existing keys
  Updating existing dictionary values
  Adding new key–value pairs
  Creating and using an empty dictionary
  Creating and accessing nested dictionaries

⚙ Dictionary Properties Highlighted

  Dictionaries store data in KEY : VALUE pairs
  Dictionaries are unordered collections
  Dictionaries are mutable (changeable)
  Duplicate keys are not allowed
  Supported data types used in this script:

Keys:

  String
  Integer

Values:
  String
  Integer
  Boolean
  List
  Dictionary (nested)
  Mutable data types like list and dictionary are not used as keys.

🔧 Dictionary Methods Used

The following built-in dictionary methods are demonstrated:
  keys() — Returns all keys of the dictionary
  values() — Returns all values of the dictionary
  items() — Returns key–value pairs as tuples
  get() — Safely access values without raising errors
  update() — Add new key–value pairs or update existing ones

▶ Execution

Run the script using:

    python Dictionary.py

🎯 Purpose

This project is intended for Python beginners to understand how dictionaries work, how data is accessed and modified, and how common dictionary methods behave during execution.

🧾 Conclusion

This script provides a clear and practical overview of Python dictionary fundamentals, focusing on real usage, nested structures, and safe data access techniques.
