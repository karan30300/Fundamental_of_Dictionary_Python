# Fundamental_of_Dictionary_Python

📘 Python Dictionary Fundamentals

This repository demonstrates the fundamental usage of Python dictionaries through a single script: Dictionary.py.

The file focuses on creating, accessing, and modifying dictionaries using basic and commonly used dictionary features.

📂 Project Structure

Dictionary.py — Demonstrates core dictionary operations in Python

🧠 Topics Demonstrated

The script covers the following dictionary concepts:

Dictionary creation using key–value pairs

Use of different data types as dictionary values

Accessing dictionary data using keys

Updating existing dictionary values

Adding new key–value pairs

Creating and working with empty dictionaries

Using nested dictionaries

Applying standard dictionary methods:

keys()

values()

items()

get()

update()

⚙ Key Characteristics Highlighted

Dictionaries are mutable data structures

Keys are unique and immutable

Values can store multiple data types

Safe value access using get() to avoid runtime errors

▶ Execution

Run the script using:

python Dictionary.py


🎯 Purpose

This project is intended for Python beginners who want a clear and practical introduction to dictionary usage without advanced concepts such as loops or comprehensions.

🧾 Conclusion

This script provides a concise and practical overview of Python dictionary fundamentals suitable for learning and revision.
